# Receitas do Estado de Pernambuco — DCA (Anexo I-C)

Visualização das receitas declaradas pelo Estado de Pernambuco ao Tesouro Nacional na Declaração de Contas Anuais (DCA), Anexo I-C (Balanço Orçamentário — Receitas), exercícios de 2019 a 2025.

Fonte: Siconfi / Tesouro Nacional, API de dados abertos (https://apidatalake.tesouro.gov.br/docs/siconfi/), extraído em setembro de 2026.

A página é um único arquivo (`index.html`) com os dados embutidos; não depende de servidor.
